# node/tx: Zcash transactions in Bend

Real mainnet v5 and v6 transactions, parsed and checked in Bend 2:

- **Parsing:** byte-level v5 (ZIP 225) and v6 (ZIP 229) layouts. That covers transparent inputs and outputs, Sapling, Orchard, and the new **Ironwood** bundle.
- **Identifiers:** the **ZIP 244 txid** and the **shielded sighash**, including the transparent-input amounts and scripts that a sighash commits to.
- **Signatures:** **RedPallas verification** of every spend-auth signature under `rk`, and of the binding signature under `bvk = Σ cv_net − [valueBalance] V`.
- **Proof inputs:** the **Halo 2 public inputs** of every action, all 10 rows: anchor, cv_net x/y, nf, rk x/y, cmx, enableSpends, enableOutputs, disableCrossAddress.

### Where the ground truth comes from (`oracle/`)
`oracle/` is a Rust program. It fetches transactions from lightwalletd (`zec.rocks`) in buckets: recent Ironwood, recent withdraw-only Orchard, Sapling-carrying, v5 NU6.2 and v5 pre-NU6.2. It parses them with `zcash_primitives` 0.31 and dumps every value. Before writing anything, it checks itself against the chain:
- **txids:** zcash_primitives recomputes each txid, and it must equal the txid lightwalletd indexed.
- **sighash:** the oracle computes it from ZIP 244 by hand, using spent-output data fetched from the previous transactions. Every on-chain spend-auth and binding signature must verify under it.
- **Halo 2 instances:** the oracle computes each instance vector independently of `orchard`'s `Instance` type. With those vectors, the **real mainnet Halo 2 proof** must verify under the official `halo2_proofs` verifier.

### Negative tests (`tamper.py`)
These run on a v6 Ironwood tx, a v5 Orchard tx and a v6 Ironwood+Sapling tx.

| Tamper | Expected and observed |
|---|---|
| one memo-ciphertext byte | txid and sighash change; all spend-auth and binding signatures fail |
| one spend-auth signature byte | txid and sighash unchanged (signatures aren't effecting data); only that signature fails |
| one binding signature byte | only the binding signature fails |
| valueBalance + 1 zatoshi | txid and sighash change; all signatures fail |

## What is real, tested, or assumed

- **Differentially tested, not proven.** The Bend code reproduces `zcash_primitives` and `orchard` outputs byte for byte on 29 real transactions, plus targeted negative tests. There are no Bend laws in this component.
- **Labelled constants.** The generators G (spend-auth), V and R (value commitment) are GroupHash outputs taken from the oracle (`consts.bend`, generated by `gen_consts.py`). They are not recomputed in Bend.
- **The Halo 2 proof itself is not verified here.** That is `../../halo2/`. This component produces the exact instance vectors that verifier consumes, and they are confirmed against the official verifier.
- **Not checked:**
  - transparent scripts (P2PKH/P2SH evaluation)
  - Sapling proofs and signatures (Groth16 / RedJubjub)
  - consensus rules that need chain state: anchors exist, nullifiers unspent, turnstile, fees, expiry
  - Orchard flag-byte validity rules, which are parsed but not enforced
  - v4 and older transactions
- **Sample limits:** no coinbase transaction carrying an Orchard bundle is in the sample (the coinbase branch is implemented but untested), and no CompactSize ≥ 253 appears except in proof lengths.

## Files

| File | |
|---|---|
| `tx.bend` | parser, ZIP 244 digests, sighash, RedPallas, bvk, instances, report |
| `tx_main.bend` | `tx_main <tx.bin> <tx.ctx>`: prints the oracle's line format |
| `blake2b.bend` | general BLAKE2b (any length, personalization, 32/64-byte output); generated by `gen_blake.py`, checked against `hashlib` (`t/b2_test.bend`: 9/9 at 0–8,197 bytes) |
| `util.bend`, `consts.bend` | hex output; generator constants |
| `oracle/` | Rust ground truth (uses `../../halo2/oracle/vendor` read-only for the raw halo2 verifying key) |
| `mainnet/` | per tx: `tx_i.bin` (raw), `tx_i.ctx` (spent amounts/scripts as hashed), `tx_i.txt` (expected), proofs; `index.txt` |
| `check.py`, `tamper.py` | differential and negative tests |

Shared libraries are imported in place: `../../halo2/lib` (words, Fp, Fq, Pallas) and the BLAKE2b round construction from `../../gpu-scan/gen.py`.

```sh
cd oracle && cargo run --release            # refresh mainnet/ (lightwalletd, ~20 s)
python3 gen_blake.py && python3 gen_consts.py
bend tx_main.bend -o tx_main                 # ~20 s native build
python3 check.py && python3 tamper.py
```
