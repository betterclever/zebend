# orchard_hash: Poseidon and Sinsemilla gates (16 laws)

Proven (`bend PROOF.bend --verdict`: ALL PROOFS CHECK, no `@unsafe`). Fp = Z/p, p = 1 + pp.
Generated by `gen.py` with `../orchard/lawgen.py`; conventions as in `../orchard_ecc/README.md`.

These gates are algebraic identities: each says "next value = expression of this row". Each
law `gate_<g>` turns "the polynomials vanish, selector invertible, cells canonical" into those
equations, in the generated polynomial's own shape; `gate_<g>_satisfiable` exhibits a row over
F_11 meeting every hypothesis.

| Gate | Facts |
|---|---|
| 21 "full round" | Poseidon full round: each next-state lane is sum_j M_ij (s_j + rc_j)^5 |
| 22 "partial rounds" | two partial rounds per row: the mid S-box output, then the second half-round equals the inverse-MDS image of the next state |
| 23 "pad-and-add" | next state = state + message, lane by lane |
| 24, 28 "Initial y_Q" | Sinsemilla: 2 y_Q from the first row's x_A, x_P, lambda_1, lambda_2 |
| 25, 29 "Sinsemilla gate" | the round's secant line (lambda_2^2 = x_A' + x_R + x_A) and y check |
| 30 "a' = b ⋅ swap + a ⋅ (1-swap)" | MerkleCRH's conditional swap (second instance; `../orchard`'s `cond_swap` is gate 26): outputs are the muxed inputs, swap is a bit |

The MDS entries are parameters (`c<hex>` in `gates_model.bend`) with the values of the
generated gates, which equal the deployed verifying keys'. This directory does not recompute
them, or the round constants (fixed columns), from the Poseidon specification.

## Not covered

- That the rounds compose to the Poseidon permutation, and that Sinsemilla's rounds compute
  the Sinsemilla hash (multi-row, and the round constants and generator tables are fixed
  columns, i.e. circuit data).
- Sinsemilla's incomplete additions never hitting an exceptional case.

## Reproduce

```sh
python3 gen.py
BEND_NO_TELEMETRY=1 bend PROOF.bend --verdict    # ALL PROOFS CHECK
```
